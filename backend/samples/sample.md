# Welcome to tokens.md

tokens.md converts files to token-efficient Markdown for LLM prompts.

## Try it

1. Drop a PDF, Word document, or spreadsheet into the workbench.
2. Convert it to Markdown and watch the token savings.
3. Merge several files into one master document.

## Features

- Convert documents, e-books, web pages, and structured data.
- Fit content to a hard token budget.
- Collapse a whole repository into a single manifest.
